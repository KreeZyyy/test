# Modular Switchboards 0.12.80

Stejná úprava jako u pojistek, nyní pro bateriovou zásuvku. Šest kontaktů je nově vytvořených s plným rovným šedým čelem a drobným zaoblením hran. Jejich pozice, obálky a hloubka jsou převzaté z dodané reference původního APC. Vnější profil zásuvky zůstává původní.

Původní samostatný tmavý a zlatý materiál je odstraněný. Zásuvka i kontakty používají skutečné herní materiály pouzdra, původní textury, UV a běžnou registraci/aktualizaci vzhledu. Zásuvka používá černou herní paletu a kontakty šedou, stejně jako opravené svorky pojistek.

Skutečná baterie, její nativní slot, orientace, velikost, vložení/vyjmutí, náboj, nabíjení a záloha se nemění. Pojistkové moduly z0.12.79 zůstávají beze změny.

Ověření: Release build bez chyb a varování. Produkční geometrické kontroly potvrzují54 průhledových bodů na šesti kontaktech, normály čel dopředu, původní hloubku kontaktů APC, všech86původních trojúhelníků těla zásuvky a nezměněný prostor/nativní uložení baterie. Dodaná reference byla porovnána s původními vrcholy. Náhled vychází ze skutečných modelů, ale není z Unity; osvětlení a čitelnost ve hře zatím vyžadují kontrolu.

Při vypnuté hře nahraď složku ModularSwitchboards v mods. Server a klienti musí mít stejnou verzi.
