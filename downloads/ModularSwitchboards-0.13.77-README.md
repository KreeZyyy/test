# Modular Switchboards 0.13.77 — matnější povrchy

Omezení odlesků baterky na rozvaděči, DIN modulech, ovladačích dveří, štítcích a kabelech. Bílé vložky štítků nyní stejně jako černé držáky vypínají zrcadlové odlesky. Materiály krytu a modulů nepřebírají původní index lesku z APC. Privátní kopie zachovávají textury, barvy, paint a emisi; původní herní materiály a skutečné vložené baterie se nemění. LED zachovávají svícení i barvy.

Funkce, ukládání, umístění a demontáž z0.13.76 se nemění. Jas přímého světla a bloom svítících LED mohou být stále výrazné; konkrétní čitelnost pod baterkou je třeba ověřit ve hře. Unity runtime zde není dostupný.

Instalace při vypnuté hře: nahraď složku ModularSwitchboards ve složce mods; host a klienti stejná verze. Ověř baterku z několika úhlů, bílé i barevné dveře, štítky, jističe, LED ON/OFF a změnu barvy. Záloha0.13.51 zachovaná.

Ověření: Release build bez chyb/varování;35 kontrol produkčního matného povrchu a izolace vlastnictví,125 kontrol LED a12 kontrol materiálu textu. Izolované testy s náhradami Unity nenahrazují kontrolu obrazu ve hře.
