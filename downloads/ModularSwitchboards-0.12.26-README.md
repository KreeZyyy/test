# Modular Switchboards 0.12.26 — vnitřní texty za dvířky

Popisky Input, Output 1 a Output 2 se při zavřené skříni nevykreslují. Při otevření jsou viditelné pouze zepředu a při nezakrytém pohledu: kontrola paprskem proti kolizím zachytí i pohybující se dvířka. Obchází se tím nativní fontový materiál, který může ignorovat hloubku. Sdílený materiál fontu se nemění; venkovní štítek názvu rozvaděče zůstává beze změny.

Geometrie, rozmístění a otočení svorkovnic z 0.12.25 i funkce elektrického Input beze změny. Venkovní výstupy a vlastní vnitřní drátování jsou stále další krok.

Instalace: při vypnuté hře nahraď složku ModularSwitchboards v Documents/My Games/Stationeers/mods/ složkou z test ZIPu. Zachovej závislosti.

Ověření: kompilace bez chyb a varování, integrita ZIPů. Viditelnost při zavření/otevření a během pohybu dvířek je třeba ověřit ve hře.
