# Modular Switchboards 0.12.67

Odstraněné vnitřní dělicí spáry také na držácích pojistek. Místo samostatných zaoblených bočních lišt a koncových bloků používá DinFuseModel.Housing přímo společné tělo jističe s vyříznutým otvorem12.5x44mm v modelových souřadnicích. Zaoblení těla a jeho stupňované čelo tak odpovídají jističi, bez dalších spojů u otvoru. Zachovaná1 DIN pozice, kontakty, původní váleček pojistky, bílá zakončení a samostatný spálený model. Zadní plocha otvoru je šedá.

Funkce pojistek, vkládání/vyjímání, napájení i bateriový modul se nemění. Mezery mezi sousedními samostatnými moduly zůstávají; odstraněné jsou dělicí spáry uvnitř jednoho držáku.

Ověření: Release build bez chyb a varování. Nové kontroly4 míst původních spár držáku pojistek porovnávají povrch s původním jističi a potvrzují shodu. Prošly i geometrické kontroly viditelnosti kontaktů, prázdného otvoru, zdravé/spálené pojistky, rozměrů a bateriového modulu. Běžný jistič zachovává všechny původní vrcholy a trojúhelníky. Výsledný vzhled vyžaduje ověření ve hře.

Při vypnuté hře nahraď složku ModularSwitchboards v mods; server a klienti stejná verze.
