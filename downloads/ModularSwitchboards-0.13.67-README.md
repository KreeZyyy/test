# Modular Switchboards 0.13.67

Odstraněn původní malý čtvercový Door Switch. V kitu zůstává kulatý **Door Round Switch** a červenožlutý **Door Main Switch**. Dveřní kit má osm variant; kulatý přepínač je poslední, osmá volba.

U hlavního i kulatého vypínače jsou akce jednotně **Turn ON** / **Turn OFF**, bez 0/I v textu.

Starý model, ikona, prefab, vyhledávání a registrace jsou odstraněné. Není ponechaný skrytý kompatibilní díl. Chování a vzhled zbývajících dílů, kabely a recepty se nemění.

Bedna dveřního kitu má nový dekorativní obsah: 6 LEDek a 6 kulatých switchů, plus po třech mainech, STOPech a propojkách. Počet LED dekorací je poloviční oproti původní bedně. Model bedny, ikona v kitu i F1 jsou aktualizované. Pořád jde o stejný kit, nikoli inventář k rozebrání.

Kontrola modelu: 150484 kontrol binárního meshe a fitu; všech 21 dílů má ověřenou oporu a neprotíná stěny. Model má 37621 vrcholů / 14992 trojúhelníků, jeden materiál. 46 kontrol ovládání prošlo.

Před přechodem odmontuj starý čtvercový vypínač a jeho vodiče, pokud je máš v savu. Nová verze tento zrušený prefab neregistruje. Záloha 0.13.51 zůstává zachovaná.

Build proti herním DLL bez chyb/varování. Kontrola zdrojů potvrzuje úplné odstranění starého typu. Host a klienti musí mít **0.13.67**.
