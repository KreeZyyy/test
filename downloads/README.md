# Station Assistant

## Aktuální verze: 0.2.0 — Gemini + hlas Windows

Stáhni [StationAssistant-0.2.0.zip](StationAssistant-0.2.0.zip?raw=true). Vypni hru a nahraď složku `Dokumenty/My Games/Stationeers/mods/StationAssistant` složkou ze ZIPu. Postup je v `INSTALACE.txt`.

Gemini klíč zadávej jen do `[Gemini] GeminiApiKey` v místním nastavení modu. Zůstaň na projektu Google AI Studio Free tier. Hlas vytváří Windows, přednostně Microsoft Jakub. Žádné OpenAI ani placené hlasové API se nevolá.

Sestavení proti dodaným herním knihovnám prošlo bez chyb. Prošlo 16 kontrol backendu a test Lua panelu. Skutečné Gemini API a hlas Jakub na Windows ve verzi 0.2 ještě vyžadují ověření u uživatele. Určeno pro singleplayer nebo místního session hostitele.

ZIP neobsahuje API klíče ani herní knihovny. Konfigurační soubory nesdílej.

Starší `StationAssistant-0.1.0.zip` používá OpenAI; pro Gemini použij výhradně verzi 0.2.0.
