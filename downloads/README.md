# Station Assistant 0.1.0

Instalační ZIP pro StationeersLaunchPad. Český chat a syntetický hlas přes OpenAI API.

Stáhni `StationAssistant-0.1.0.zip`, rozbal složku `StationAssistant` do `Dokumenty/My Games/Stationeers/mods` a postupuj podle `INSTALACE.txt` uvnitř.

Mod byl sestaven proti dodaným herním knihovnám bez chyb. Backend a Lua panel prošly automatickými kontrolami. Načtení a zvuk ve hře ani skutečné API dosud nebyly ověřené. První verze je pro singleplayer nebo místního session hostitele.

API klíč nastav pouze na svém PC. ZIP neobsahuje API klíče ani knihovny z instalace hry.
