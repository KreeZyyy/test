# Modular Switchboards 0.11.3 — bez zadního korpusu a přípojek

Vypnuto vytváření tmavého zadního korpusu, jeho úchytů i všech tří vnějších kabelových přípojek (Input, Output, Output2). Přípojky se nevytvoří ani vizuálně, ani jako nové síťové uzly. Bílá skříň a vnitřní osazení zůstávají.

DLL je přímá úprava originálu 0.11.3: InstallRearBody ihned skončí a TryInstall ihned vrátí false. Zbytek DLL je beze změny. Nejde o novou kompilaci. Integrita ZIPu a rozsah změn ověřeny; ve hře zatím netestováno.

Vypni hru. Zazálohuj původní mod a nahraď složku ModularSwitchboards v Documents/My Games/Stationeers/mods/ složkou ze ZIPu. Ponech závislosti. Klient i server musí používat stejný balíček. Již položené kabely balíček ze světa nemaže.
