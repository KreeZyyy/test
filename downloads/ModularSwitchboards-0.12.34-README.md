# Modular Switchboards 0.12.34 — Input a dva samostatné výstupy

Spodní přípojky jsou funkční nativní elektrické porty: při pohledu na předek rozvaděče vlevo Output 1, vpravo Output 2. Každý používá vlastní ověřenou kabelovou buňku. Geometrie a textury z 0.12.33 zachované.

Vnitřní svorkovnice Input, Output 1 a Output 2 vyhledávají vlastní přípojku podle role a zpřístupňují její skutečný kabel a síť. Funguje i Input; nepoužívá se společná cache prvního kabelu. Namíření na svorkovnici zobrazí nativní údaje odpovídající přípojky. Vnitřní propojení mezi vstupem a výstupy zatím není — bude součástí našeho drátování.

Instalace: při vypnuté hře nahraď složku ModularSwitchboards v Documents/My Games/Stationeers/mods/ složkou z test ZIPu. Zachovej závislosti.

Ověření: kompilace bez chyb a varování; produkční přístupové vlastnosti svorkovnic proti odděleným sítím, změně pořadí portů a stavům náhledu/rámu/prefabu; rollback při třech částečných selháních; integrita ZIPů. Skutečné připojení kabelů, tooltipy a ukládání je nutné ověřit ve hře.
