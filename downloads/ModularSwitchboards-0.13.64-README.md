# Modular Switchboards 0.13.64

Název dveřní sady sjednocen na **Kit (Switchboard Door Modules)** v inventáři, nabídce spawnování, F1 i dalších místech používajících název prefabu. Původní automatický název „Switchboards Doors Module“ v uloženém předmětu se při načtení převede na nový. Vlastní přejmenování hráčem zůstává zachované.

Model bedny, ikony, recept, počet kusů, varianty, prefab ID a veškeré chování zůstávají stejné jako v 0.13.63. Build proti herním DLL bez chyb a varování.

Host a klienti musí mít **0.13.64**. Záloha **0.13.51** zůstává zachovaná.
