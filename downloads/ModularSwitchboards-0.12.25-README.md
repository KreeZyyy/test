# Modular Switchboards 0.12.25 — orientace svorek a čitelné štítky

Horní svorkovnice Input otočená o 180 stupňů v rovině montážní desky; pevný zadní vodič vede nahoru. Posunutá o 16 mm výš na Y=0.211 m. Obě spodní svorkovnice jsou o 16 mm níž na Y=-0.211 m, natočení zachované. Přední kontaktní body se transformují se svorkovnicí.

Opravené levé/pravé při pohledu do otevřené skříně: Output 1 vlevo, Output 2 vpravo. Pozice X jsou proti předchozí verzi vyměněné podle skutečného pohledu na herní model.

Popisky nově na samostatných bílých štítcích s tmavým okrajem a tučným černým textem, rozlišení fontu 128. Velikost textu přizpůsobená ploše 60 × 12 mm. Input má štítek vedle svorkovnice, spodní výstupy nad ní. Štítky se neotáčejí s horní svorkovnicí a bílý podklad zůstává zachovaný i při lakování skříně.

Jeden kontakt, jeden šroub a jeden zadní vodič na svorkovnici zůstávají. Funkce horního venkovního Input beze změny; Output 1/2 jsou stále příprava pro budoucí venkovní výstupy a vlastní vnitřní drátování. Svorkovnice se automaticky nepropojují.

Instalace: při vypnuté hře nahraď složku ModularSwitchboards v Documents/My Games/Stationeers/mods/ složkou z test ZIPu. Zachovej závislosti.

Ověření: kompilace bez chyb a varování, rozměrová kontrola vůči hranám zadní desky a spodní řadě DIN modulů, integrita ZIPů. Výslednou čitelnost, levé/pravé a polohu je třeba ověřit ve hře.
