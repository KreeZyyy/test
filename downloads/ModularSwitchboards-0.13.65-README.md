# Modular Switchboards 0.13.65

## Door Switch

Nový menší ruční otočný vypínač je **osmá varianta** v kitu **Kit (Switchboard Door Modules)**. Světlá destička 40×40 mm, tmavý rámeček, černá nízká rukojeť a šedý šroubek. Pevné černé 0 vlevo a I nahoře jsou přímo na destičce; nemá clonu ani okénko. Původní červenožlutý Door Main Switch zůstává samostatnou variantou se stejným modelem a chováním.

0 rozpojí IN od OUT, I propojí, bez ochrany proti přetížení. Rukojeť se plynule otočí o 90°. Ovládání funguje bez napájení i při zavřených dveřích. Nativní OnOff ukládá a synchronizuje stav. Při přípravě modelu se nepřistupuje k dosud nedostupnému stavu.

Jeden kit na kus, existující zadní svorky a devět dveřních pozic. Předchozích sedm variant a jejich pořadí se nemění. Vlastní ikona je v nabídce kitu i F1, pokládání má náhled skutečného modelu. Bedna kitu si ponechává dosavadní dekorativní obsah.

Ověření: build proti herním DLL bez chyb/varování; 43 kontrol společného produkčního ovládání/animace a vodivosti, včetně stavu při načtení a přípravy prefabu. Ikona vyrenderována a zkontrolována. Vzhled, pokládání a zapojení ještě zbývá ověřit ve hře.

Host a klienti musí mít **0.13.65**. Záloha **0.13.51** zůstává zachovaná.
