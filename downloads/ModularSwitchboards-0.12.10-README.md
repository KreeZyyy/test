# Modular Switchboards 0.12.10 — IN model otočený o 180 stupňů

Na žádost uživatele otočen model napájecího panelu o 180 stupňů kolem vlastní příčné osy X, se zachováním kotevního bodu na kabelové mřížce. Zůstává nahoře uprostřed, v původní velikosti. Šedý panel, blesk a kontakty se otáčejí jako jeden model.

SocketPoint, SocketAxis a cílové buňky pro budoucí kabel se nemění. Nové metadata PanelFaceAxis popisují skutečné natočení vizuálního čela odděleně od logické osy. Model se otáčí kolem původní nativní napájecí kotvy, která je počátkem jeho meshe. Žádné ruční posunutí z mřížky se neprovádí. Uchycení a další navazující modelové díly zůstávají na další krok.

Pořád jen model: FunctionalConnection=false, žádná nová Connection, síť ani elektrické propojení. Zbytek potvrzené skříně zůstává stejný. Statický F1 náhled runtime IN nezobrazuje.

Instalace: při vypnuté hře nahraď složku ModularSwitchboards v Documents/My Games/Stationeers/mods/ složkou z test ZIPu. Ponech závislosti; klient a server potřebují stejnou verzi.

Ověřeno: kompilace proti dodaným herním knihovnám, 0 chyb a 0 varování, integrita ZIPů. Natočení a návaznost modelu je třeba ověřit ve hře.
