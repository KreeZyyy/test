# Modular Switchboards 0.13.66

## Door Round Switch

Nový kulatý ruční přepínač má průměr 32 mm jako objímka LEDky: tmavý podklad, stříbrná objímka, černá krátká páčka a světlá plocha na jejím čele. Nemá čtvercovou destičku ani otočné okénko.

Je **devátou variantou** v **Kit (Switchboard Door Modules)**, za dosavadními osmi díly. Původní Door Switch i červenožlutý Door Main Switch zůstávají. Jeden kit na kus, stejné zadní horní/spodní kontakty a stejných devět dveřních pozic.

Vlevo je 0/OFF, vpravo I/ON. Páčka se plynule otočí o 90° mezi dvěma šikmými polohami. 0 rozpojí, I propojí bez nadproudové ochrany. Ovládání funguje bez napájení a s otevřenými i zavřenými dveřmi; používá nativní uložený/síťový OnOff. Příprava modelu stav nečte ani neresetuje.

Vlastní ikona je v kitu i F1. Náhled pokládání používá skutečný model. Mřížka, držáky štítků, EMERGENCY štítek a velikost hlavního vypínače se v této verzi nemění; štítky jsou plánovaná další práce. Dekorativní obsah bedny kitu zůstává dosavadní.

Ověření: produkční build proti herním DLL bez chyb/varování. 46 kontrol skutečného společného ovladače/animace včetně obou poloh kulatého přepínače, uloženého stavu a serverových interakcí. Kontrola bezpečné přípravy prefabu; ikona renderována a zkontrolována. Živý test velikosti, páčky, pokládání a zapojení ještě zbývá.

Host a klienti musí mít **0.13.66**. Záloha **0.13.51** zůstává zachovaná.
