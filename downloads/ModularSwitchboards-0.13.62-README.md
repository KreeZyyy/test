# Modular Switchboards 0.13.62

Vnitřní červený kruh otočného vypínače je sloučený s druhým kruhem do jedné rovné čelní plochy. Clona má vyplněný střed ve stejné výšce; zůstává jen jediné okénko pro 0/I a vyšší vnější lem. Mezi středem a clonou už není kruhový schod.

Středový šroubek je šedý s tmavou drážkou. Malé rozměry, rukojeť, plynulé otočné okénko s bílým podkladem, svorky a elektrické chování zůstávají stejné. Oprava viditelnosti dveřních kabelů s nasazeným krytem desky je zachovaná.

Ověření: produkční build bez chyb/varování; 18192 kontrol skutečné geometrie včetně uzavřeného sjednoceného středu a clony, zakrytí značek a bílého podkladu v celé dráze okénka. Kontroly viditelnosti kabelů a bezpečné přípravy prefabu. Vizuální test ve hře ještě zbývá.

Host a klienti musí mít **0.13.62**. Záloha **0.13.51** zůstává zachovaná. Při přechodu z experimentální 0.13.52 nejdřív odmontuj zrušený dveřní analyzer a jeho vodiče.
