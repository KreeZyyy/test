# ModularSwitchboards 0.12.85

Input, Output 1 a Output 2: podklady štítků jsou přisazené na montážní desku (povrch z=.013 m), místo původního odsazení téměř 2 cm. Text je 0.1 mm nad bílým povrchem štítku. Umístění svorek, kabely, bateriový držák a pojistky zůstávají stejné.

Nahraď složku ModularSwitchboards při vypnuté hře. Závislosti ponech nainstalované. Sestavení a polohy povrchů ověřeny; vzhled ověř ve hře.
