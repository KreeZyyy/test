# Modular Switchboards 0.12.73

Pojistky mají původní hladký váleček s bílými konci a pouze dvě malé zaoblené podpěry schované za jejich zakončeními. Výrazné extrudované čelisti U byly odstraněné. Podpěry jsou v modelových souřadnicích10.5x4.5x12mm, u konců y=+/-14mm, nejpřednější plocha z=.0465, tedy pod původními bílými konci. Bílé konce, barevná pojistka a spálený model se nemění. Šedé prohlubně a jejich vnitřní stěny zůstávají uzavřené.

Zlaté kontakty zásuvky mají nyní kovovost0, lesk0, vypnuté zrcadlové odlesky a lesklé odrazy. Zlatá barva zůstává. Kontakty pojistek nadále používají matný světlý materiál se stejným vypnutím odlesků. Obě sady kontaktů používají běžné difuzní nasvícení; nejde o svítící materiál.

Baterka se zásuvkou jsou zvětšené o10% oproti0.12.72. Zásuvka nadále lícuje s čelem a zachovává přesný tvar APC. Tělo zůstává na2 DIN pozicích. Aby větší skutečná baterie nenarazila do zadní stěny, je pouze zadní kryt bateriového těla o několik milimetrů zapuštěnější; držáky pojistek a běžné jističe tuto změnu nemají. Slot, nabíjení, záloha, ochrany a uložený náboj se nemění.

Ověření: Release build bez chyb a varování. Produkční geometrické kontroly potvrdily dvě menší podpěry a jejich viditelnost, původní zakončení pojistek, uzavřený spodní okraj, větší otvor, shodnou přední rovinu zásuvky a prostor vůči upravenému zadnímu krytu. Všechny vrcholy zásuvky stále odpovídají profilu APC v daném měřítku. Původní běžný jistič zůstává geometricky shodný. Skutečný vzhled a chování odlesků na dálku je třeba potvrdit ve hře.

Při vypnuté hře nahraď složku ModularSwitchboards v mods; server a klienti stejná verze.
