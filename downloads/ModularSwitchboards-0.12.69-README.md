# Modular Switchboards 0.12.69

Uzavřené vnitřní stěny otvorů držáků. Při vyřezávání otvoru z těla se odstranily přední a zadní trojúhelníky, ale nebyly doplněné stěny řezu; při pohledu shora proto šlo vidět skrz spodní okraj do rozvaděče. Výřez nyní má spodní, horní i obě boční vnitřní plochy, se správným směrem normál do dutiny. Používají šedý materiál interiéru. Společná oprava se týká výřezů pojistek i bateriového modulu; otvor pro vlastní vložený předmět zůstává volný.

Kontakty pojistek jsou sjednocené do souvislého extrudovaného profilu U místo tří samostatně zaoblených tyček. Jsou kratší a méně vysoké vůči pojistce: krajní poloha konců je +/-19mm místo přibližně21mm v modelových souřadnicích, nejpřednější plocha je z=.0545 místo.059. Zůstává průchod pro bílé konce pojistky i původní kovový materiál. Prázdný držák má kontakty stále viditelné, výměna a elektrické funkce se nemění.

Ověření: Release build bez chyb a varování. Pohledový paprsek dolů uvnitř produkčního otvoru nyní zasáhne šedou spodní vnitřní stěnu v y=-22mm. Kontroly viditelnosti kontaktů potvrzují nové nižší čelo a jejich kratší obrys. Prošly kontroly geometrie kontaktů a pojistek, volného místa, spár a původního jističe, bateriové orientace a šedého lemu. Skutečný pohled shora a proporce kontaktů ještě potřebují potvrzení ve hře.

Při vypnuté hře nahraď složku ModularSwitchboards v mods; server a klienti stejná verze.
