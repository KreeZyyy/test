# Modular Switchboards 0.12.53

Bateriový modul má nyní jen vycentrovanou zásuvku APC s kontakty. Přebytečný krycí plech a čtyři šrouby APC jsou odstraněné. Zásuvka má šířku 40 mm; modul zůstává na 3 DIN pozicích. Skutečná baterie, její barvy, nativní ovládání, nabíjení a zálohování zůstávají zachované. Klíč názvu slotu se nyní přebírá přímo z původního APC namísto pevného řetězce Battery.

Ověřeno: Release build bez chyb a varování; test původní APC geometrie vybírá 134 trojúhelníků samotné zásuvky a kontaktů, ověřuje vystředění a uložení do těla. Produkční testy geometrie pojistek prošly. Vzhled, tooltip a interakce vyžadují ověření ve hře.

Instalace při vypnuté hře: nahraď složku ModularSwitchboards ve složce mods. Server a klienti musí mít stejnou verzi. Elektrické chování se v této verzi nemění; dříve hlášené shoření výstupního kabelu po výměně pojistky tato úprava neřeší.
