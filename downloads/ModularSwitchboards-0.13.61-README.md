# Modular Switchboards 0.13.61

Opraveno skrývání dveřních kabelů po nasazení vnitřního krytu desky. Kabely desky se dál skrývají pod krytem; kabely na vnitřní straně dvířek zůstávají při otevřených dveřích viditelné i s nasazeným krytem. Pravidla editace kabelů zůstávají stejná.

Okénko otočného vypínače má souvislý bílý prstenec pod celou dráhou otáčení. Mezi polohami 0/I už pod otvorem není červená mezera. Červená clona dál zakrývá nevybranou značku, otáčí se společně s rukojetí a odkrývá 0 vlevo nebo I nahoře. Podklad je jediný mesh bez překrytí dvou vložek. Spodní okraj rukojeti má rovný profil bez předchozího zkoseného přechodu.

Zachované malé rozměry, mělké čelo, svorky, elektrické chování, ukládání a síťová synchronizace. Zachovaná oprava bezpečné přípravy prefabu.

Ověření: build proti herním DLL bez chyb/varování; 17823 kontrol produkční geometrie včetně bílého podkladu pod celou kruhovou dráhou, zakrývání značek a rozměrů. 8 kontrol skutečných podmínek viditelnosti kořenů kabelů pro kombinace otevření dveří a nasazení krytu. Kontrola přípravy prefabu. Živý vizuální test ve hře ještě zbývá.

Host a klienti musí mít **0.13.61**. Záloha **0.13.51** zůstává zachovaná. Při přechodu z experimentální 0.13.52 nejdřív odmontuj zrušený dveřní analyzer a jeho vodiče.
