# Modular Switchboards 0.13.54

Přidána červená dveřní LED do stejného dveřního kitu (šestá varianta). Původní pořadí zelená/modrá/bílá/STOP/bridge zůstává stejné.

Stejný model, rozměry, zelený/červený náhled umístění, zapojení, spotřeba kitu i chování jako ostatní LED. Zhasnutá má tmavě červené sklíčko, zapnutá sytě červený svit a stejnou malou záři. Stávající LED ani jejich vzhled se nemění.

Host a klienti musí mít verzi 0.13.54. Záloha 0.13.51 zůstává zachovaná. Při přechodu z experimentální 0.13.52 nejdřív odmontuj zrušený dveřní analyzer a jeho vodiče.

Build ověřen proti herním DLL; ověření skutečného DoorLedView pokrývá čtyři barvy, zapnutí/vypnutí, emisivní materiál, světlo, nezávislé instance a náhled. Vizuální test vyžaduje hru.
