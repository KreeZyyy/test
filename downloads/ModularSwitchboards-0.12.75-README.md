# Modular Switchboards 0.12.75

Přepracování vnitřní konstrukce pojistkového i bateriového modulu. Oba mají jednu souvislou šedou vložku od čela k plným zádům, místo tří překrývajících se sad stěn. Vnější silueta a materiálové role zůstávají sjednocené s jističi, bez přidaných dělicích čar.

Úchyty pojistky jsou znovu vytvořené jako dva kompaktní půlkruhové držáky otevřené dopředu. Nemají obdélníkové podpěry s vyříznutou dírou. Vnitřní poloměr8.4mm, vnější10mm, původní bílé konce8.2mm. Každá plocha má explicitně ověřený směr a uzavřený objem. Barevná pojistka, bílé konce a spálená varianta zůstávají.

Bateriová zásuvka zachovává přesný profil APC, šest zlatých kontaktů, uzavřená záda a skutečný nativní slot pro baterii. Je vložená do nové souvislé dutiny. Kontakty a tělo mají samostatné skutečné mesh geometrie bez zdvojených neviditelných vrcholů. Kontakty jsou matné, bez emise a odlesků; bez příjmu stínů zůstávají pouze drobné kontakty. Tělo má běžné stínování. Velikost z0.12.73 a dvě DIN pozice zachované.

Funkce, vložené předměty, náboj, nabíjení, záloha, ochrany a uložení se nemění.

Ověření: Release build; produkční geometrické kontroly původního jističe, plné hloubky vložky, kruhových úchytů, všech normál a orientací kontaktních trojúhelníků, skutečného profilu APC, rozdělení povrchů a prostoru pro baterii. Vzhled nebyl ověřen ve hře.

Při vypnuté hře nahraď složku ModularSwitchboards v mods; server a klienti stejná verze.
