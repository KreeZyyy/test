# ModularSwitchboards 0.12.88

Názvy modulů jsou nyní DIN Cable Analyzer a DIN Battery Backup, bez závorek s počtem pozic. Při načtení uložené hry se přejmenují také původní výchozí názvy s (3 slots)/(2 slots). Vlastní názvy hráče se zachovávají.

Instalace: při vypnuté hře nahraď složku ModularSwitchboards. Ověřeno sestavení proti herním knihovnám.
