# Modular Switchboards 0.12.17 — profil I u skříně, zaoblené V směrem ven

Úprava přechodového těla podle odsouhlaseného bočního profilu. Stěna směrem ke skříni je rovná a svislá po celé viditelné výšce (I), pouze s drobným zaoblením hran. Vnější stěna se rozšiřuje k panelu (V) plynulým zaobleným přechodem v posledních 60 mm. Tunel se tedy nevyklání oběma stěnami ani se neseřizuje podle boku původního šedého pláště; referencí je střední podstavec a horní panel.

Spodní šířka zůstává 50 mm. Hloubka dříku se odvodí tak, aby měl pevnou vnitřní rovinu navazující na panel a současně zasahoval nejméně 10 mm za přední rovinu podstavce. Spodek je vertikálně zapuštěný do podstavce, horní otvor zůstává volný pro zapuštěný konektor. Poloměry a povrch pokračují z předchozí verze.

Panel, konektor, jejich umístění a nativní metadata jsou beze změny. Původní Cabinet.meshbin také beze změny. Stále pouze model bez funkčního kabelového připojení či vnitřního drátování.

Instalace: při vypnuté hře nahraď složku ModularSwitchboards v Documents/My Games/Stationeers/mods/ složkou z test ZIPu. Ponech závislosti.

Ověřeno: kompilace bez chyb a varování; produkční výpočet geometrie přes matematický harness pro pět wall-fit offsetů. Ověřena svislá vnitřní stěna, vnější rozšíření, konstantní dřík, vnější orientace nedegenerovaných trojúhelníků a pouze horní otevřená hranice. Překryv s podstavcem zkontrolovaný pro běžné wall-fit offsety do 0.125 m. Integrita ZIPů ověřena. Ve hře zde netestováno; skutečný vizuální spoj je třeba potvrdit.
