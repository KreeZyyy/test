# Modular Switchboards 0.12.24 — jeden kontakt a vodič na svorkovnici

Oprava podle herní mechaniky Stationeers: každá ze tří svorkovnic (Input nahoře, Output 1 dole vlevo, Output 2 dole vpravo) má jediný kontakt pro vlastní drátování, jeden šroub a jeden červený zadní vodič skrz montážní desku. Žádná dvojice pólů ani nulový vodič. Umístění a popisky zachované.

Input odkazuje na existující venkovní elektrický vstup. Output 1 a Output 2 jsou zatím připravené svorkovnice; venkovní výstupy ani vlastní vnitřní drátování nejsou v této verzi přidané. Zadní vodiče jsou vizuální a svorkovnice se automaticky nepropojují.

Instalace: při vypnuté hře nahraď složku ModularSwitchboards v Documents/My Games/Stationeers/mods/ složkou z test ZIPu. Zachovej závislosti.

Ověření: kompilace bez chyb a varování, kontrola registrace očekává tři svorkovnice s jedním předním a zadním bodem. ZIPy ověřeny. Vzhled ještě vyžaduje kontrolu ve hře.
