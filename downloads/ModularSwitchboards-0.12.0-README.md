# Modular Switchboards 0.12.0 — krok 1, integrovaný zadní plášť

Šedé pokračování je součástí hlavního Housing meshe rozvaděče, včetně kolize. Navazuje na celý zadní obrys 400 × 500 mm se stejnými 20mm rohy. Nemá úchyty, krabici s bleskem ani kabelové přípojky. Původní předek, dvířka a vnitřní osazení jsou zachované.

Model, GLB, F1 ikona a vložený Cabinet.meshbin byly znovu exportovány z Blenderu. Základní hloubka zadního pláště v assetu je 50 mm. Při přípravě prefabů se hloubka přizpůsobí zadnímu přesahu širokých ploch hlavního meshe herního APC; drobné přípojky a vystouplé díly nejsou cílem měření. Tento způsob odhadu musí potvrdit herní test. Při nedostupném/neplatném měření se použije 50 mm a varování v Player.log.

V Player.log hledej `Integrated rear shell: APC broad-face depth=` nebo `APC rear depth measurement unavailable`. Pro případnou korekci pošli boční screenshot a příslušný řádek logu.

Instalace: vypni hru, zazálohuj původní mod a nahraď složku ModularSwitchboards v Documents/My Games/Stationeers/mods/ složkou z test ZIPu. Stávající závislosti ponech. Klient i server musí mít stejnou verzi. Již položené kabely se nemažou.

Ověření: skutečná kompilace proti dodaným knihovnám bez chyb a varování. Geometrické kontroly ověřily rozměry, přiřazení šedého materiálu, normály, indexy a nezměněné původní vrcholy pláště, rámu, dvířek a vnitřku. Ve Stationeers zde nespouštěno.
