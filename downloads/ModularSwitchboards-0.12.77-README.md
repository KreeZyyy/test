# Modular Switchboards 0.12.77

Kontakty pojistek používají přesně stejný bílý materiál jako bílé čepičky pojistky. Jde o sdílenou instanci materiálu, nikoliv další pokus o kovový vzhled. Samostatný stříbrný materiál byl odstraněn. Kontakty nadále nepřijímají drobné vlastní stíny.

Tvar kontaktů, vnitřní vanička i celé ostatní modely zůstávají přesně jako v0.12.76. Bateriový modul se nemění. Cílem je čitelnější bílý povrch z dálky; skutečný výsledek osvětlení je nutné potvrdit ve hře.

Ověření: Release build bez chyb a varování. Přímé porovnání zdrojů ověřilo, že produkční geometrie, baterie a elektrické chování jsou beze změny. Geometrické a elektrické kontroly z0.12.76 tedy platí pro stejný kód. Instalaci ani vzhled zatím neověřila Unity scéna.

Při vypnuté hře nahraď složku ModularSwitchboards v mods. Server i klienti musí mít stejnou verzi.
