# Modular Switchboards 0.12.74

Malé matné podpěry pojistek mají skutečný půlkulatý výkus podle bílých konců: poloměr 8.4 mm pro zakončení 8.2 mm. Uzavřené stěny držáku, původní pojistka i její konce zůstávají.

Zlaté kontakty baterky mají samostatný renderer bez příjmu a vrhání stínů. Dutina dál používá běžné stíny. Kontakty zůstávají matné, bez kovových odlesků a bez emise; jejich původní APC geometrie a normály se nemění. Samostatný renderer je vyřazen z přebarvování skříně. Tato změna cílí na černání drobných kontaktů na dálku, výsledek je nutné potvrdit ve hře.

Velikost baterie a zásuvky, dvě DIN pozice, nativní slot, nabíjení a záložní napájení se nemění.

Ověření: Release build bez chyb a varování; geometrické kontroly včetně poloměru obou výkusů, původního profilu APC, průchodnosti otvoru, uzavřených stěn a původního jističe. Hra není v tomto prostředí dostupná.

Při vypnuté hře nahraď složku ModularSwitchboards v mods; server a klienti stejná verze.
