# Modular Switchboards 0.12.76

Tato verze upravuje pouze vzhled pojistkových držáků. Nová uzavřená vnitřní vanička má plnou zadní stěnu, oba boky, horní i spodní stěnu a zkosené rohy. Její dno je mělčí, aby za pojistkou nebyla hluboká tmavá dutina. Vnější pouzdro a svorky vycházejí z dosavadního základu.

Nové stříbrné kontakty tvoří dvě pružné objímky s otevřeným čelem a zadními montážními patkami. Objímky obepínají bílé konce pojistky, jejich širší okraje zůstávají viditelné. Barevné tělo pojistky, bílé konce a rozbitá varianta jsou zachované. Kontakty mají samostatný matný materiál a nepřijímají drobné vlastní stíny.

Bateriový modul a jističe jsou beze změny oproti 0.12.75. Identifikátory, zapojení, náboj, jištění, ukládání a multiplayerové chování se nemění.

Ověření: Release build bez chyb a varování. Produkční geometrický harness ověřil všech pět vnitřních stěn, uzavřenost vložky, viditelnost kontaktů a orientaci trojúhelníků. Prošly regresní kontroly baterie, modulů, energie, zapojení a ukládání. Náhled je vytvořený z produkčních vrcholů; nepředstavuje herní osvětlení ani ověření shaderu v Unity. Skutečný vzhled ve hře ještě vyžaduje kontrolu.

Instalace při vypnuté hře: nahraď složku ModularSwitchboards v mods. Server i klienti musí mít stejnou verzi. Do distribučního ZIPu nejsou přibalené žádné knihovny hry ani závislostí.
